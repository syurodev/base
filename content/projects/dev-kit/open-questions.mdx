# Open questions

Những câu hỏi vẫn cần quyết định product/platform. Các lựa chọn đã chốt nằm ở [Architecture decisions](/dev-kit/architecture-decisions).

## Đã chốt (xem ADR)

- **SSH vs DB priority** → [ADR-002](/dev-kit/architecture-decisions#adr-002-internal-modules-before-external-plugins): cả hai ship như built-in modules phase đầu.
- **SQLCipher vs application-layer encryption** → [ADR-004](/dev-kit/architecture-decisions#adr-004-application-layer-encrypted-records-instead-of-sqlcipher): mã hóa field ở application layer; không SQLCipher trong phase hiện tại.
- **Transport security cho connections** → [ADR-007](/dev-kit/architecture-decisions#adr-007-verified-tls-for-remote-db-and-exact-ssh-host-key-pinning).

## Product (chưa chốt)

1. Notes: Markdown only hay rich text có code-focused extensions?
2. Paid feature đầu tiên: sync, pro tools, team vault, hay marketplace?

## Platform (chưa chốt)

1. Plugin runtime tương lai: JS, WASM, external process, hay kết hợp?

## How to use this page

- Mỗi quyết định được chốt → chuyển thành ADR trong [Architecture decisions](/dev-kit/architecture-decisions).
- Không để open questions block local-first MVP nếu chưa cần.
