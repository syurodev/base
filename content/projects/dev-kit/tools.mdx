# Tools

Tools là các utility built-in đăng ký vào command registry — pattern hiện tại có hash generator và khung đăng ký lệnh/view. Format/convert/snippet runners là mở rộng product future, không phải runtime hiện tại.

```mermaid
flowchart LR
  PALETTE[Command palette] --> REG[Command registry]
  REG --> TOOL[Tool module]
  TOOL --> UI[Tool view]
```

## Principles

- Tool không tự ý đọc vault nếu chưa có capability.
- Ưu tiên built-in trước khi mở SDK ngoài.
- Mỗi tool có entry rõ trong registry để search/palette dùng được.
