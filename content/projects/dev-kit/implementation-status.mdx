## Current limitations

- SQLite storage is application-layer encrypted via vault envelopes and file
  permissions, not full-disk database encryption.
- Note titles stay plaintext local metadata for now.
- SSH covers profiles (required `env` tag), exact host-key trust, test connection,
  command execution, and loopback-only local/remote TCP forwarding. Forward
  sessions are runtime-only and stop on profile delete / app shutdown. MCP sticky
  active profile + env confirmation gate are Implemented.
- Database Postgres profiles cũng bắt buộc `env`; multi-engine vẫn design. MCP
  active profile + confirmation Implemented.
- Kafka profiles bắt buộc `env`; UI/bridge path Implemented (profiles, connect,
  topics, peek, consumer groups, publish). MCP tools + cluster-selection popup +
  env confirmation Implemented (headless fail-fast).
- Environments Settings quản lý tag; `DeleteTag` scan gồm `kafka-profile`;
  `RequiresConfirmation` fail-closed feeds MCP confirmation (env wins over
  `allow_always`).
- MCP: Implemented runtime (socket host, stdio proxy, tools, install for
  `claude-code`/`codex` × `global`/`project`). Resources / Streamable HTTP
  deferred. Not production-verified against a real Claude Code session in CI.
- Agent Hub is **Implemented** (Phase 4 Claude-only): ACP + service +
  mock/Claude + bridge/UI + `agenthub.*` MCP tools. Codex/Gemini adapters still
  Design (not required to close Phase 4). Not claimed production-verified against
  real Claude Code in CI.
- External plugin runtime is still design-only (**Phase 6**; marketplace
  **Phase 7** — after Workbench UI Phase 5).
- Sync client hiện có server-authoritative account session, runtime-only bearer,
  HTTPS transport (HTTP chỉ cho loopback), encrypted push/pull, transactional
  apply/cursor, replay journal, durable local mutation intents, capability-gated
  bridge, minimal Sync UI, và **Git-style conflict resolve** (list / capture
  theirs / resolve ours|theirs|`merge` notes-only). Local mutation, version và intent
  commit atomically; ACK cũ không được đánh dấu edit mới hơn là synced. Không
  có auto-winner. Companion backend đã có registration/revocation guard và
  durable arbitration. Desktop dùng PKCE loopback + rotating refresh token trong
  OS keychain; access token không persist và Gateway origin được pin. Deployed
  matrix G1–G4 pass qua `cmd/synce2e/` trên Compose stack (`7708b99`). JetBrains
  3-pane merge UI thuộc **Phase 5 Workbench UI**, không phải blocker Phase 3.
- `ModuleManifest` hiện là contract cho built-in modules với các fields
  `id`, `title`, `version`, `apiVersion`, `commands`, `views`, `capabilities`.
  Backend registry có validation, duplicate protection, deterministic list và
  caller-owned snapshot; `ListModules` chỉ expose public metadata; frontend
  built-in manifests parity-check với backend. Workbench có loading/error,
  compatibility warning, unavailable-module và empty states ở mức tối thiểu.
  `capabilities` chỉ là declaration metadata, grants vẫn do capability
  gateway/policy quản lý.
- External plugin runtime, dynamic loading, và marketplace vẫn ngoài scope của
  Phase 2; sync được triển khai riêng trong Phase 3. MCP runtime + install đã
  Implemented (Resources / Streamable HTTP deferred).
- Vault-item repository is now implemented: một bảng `vault_items` + `internal/vaultitem`
  store, notes/database/ssh là thin adapter, cross-type search qua `VaultSearch`.
  Cross-type search hiện là substring trên metadata JSON và chưa có index trên cột `type`.
- Go packages domain nằm trực tiếp dưới `internal/` (không còn `internal/services/`).
  Sync persistence ở `internal/syncstore`; conflict orchestration ở
  `internal/syncconflict`. Xem [`/dev-kit/repo-structure`](/dev-kit/repo-structure).
