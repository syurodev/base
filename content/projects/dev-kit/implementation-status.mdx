## Current limitations

- SQLite storage is application-layer encrypted via vault envelopes and file
  permissions, not full-disk database encryption.
- Note titles stay plaintext local metadata for now.
- SSH covers profiles, exact host-key trust, test connection, command execution,
  and loopback-only local/remote TCP forwarding. Forward sessions are runtime-only
  and are stopped when the profile is deleted or the app shuts down.
- MCP runtime is still design-only in this checkout.
- External plugin runtime is still design-only in this checkout.
- Sync client hiện có server-authoritative account session, runtime-only bearer,
  HTTPS transport (HTTP chỉ cho loopback), encrypted push/pull, transactional
  apply/cursor, replay journal, capability-gated bridge và minimal UI. Backend
  production, token refresh, server-side registration/revocation proof và
  automatic capture local create/update/delete vào outbox vẫn chưa có. Vì vậy
  local dirty state được bảo vệ fail-closed và có thể dừng pull bằng conflict.
- `ModuleManifest` hiện là contract cho built-in modules với các fields
  `id`, `title`, `version`, `apiVersion`, `commands`, `views`, `capabilities`.
  Backend registry có validation, duplicate protection, deterministic list và
  caller-owned snapshot; `ListModules` chỉ expose public metadata; frontend
  built-in manifests parity-check với backend. Workbench có loading/error,
  compatibility warning, unavailable-module và empty states ở mức tối thiểu.
  `capabilities` chỉ là declaration metadata, grants vẫn do capability
  gateway/policy quản lý.
- External plugin runtime, dynamic loading, marketplace và MCP runtime vẫn ngoài
  scope của Phase 2; sync được triển khai riêng trong Phase 3.
- Vault-item repository is now implemented: một bảng `vault_items` + `internal/services/vaultitem`
  store, notes/database/ssh là thin adapter, cross-type search qua `VaultSearch`.
  Cross-type search hiện là substring trên metadata JSON và chưa có index trên cột `type`.
- The docs `bun run types:check` command currently reports an unrelated generated
  `.source/server.ts is not a module` error; the production docs build completes
  successfully with TypeScript.
