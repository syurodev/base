# DevKit

DevKit is a cross-platform, local-first desktop workspace for developers. It combines daily utilities, encrypted personal knowledge, secure connection management, and an extensible plugin platform — all designed to work offline with a strong security model for sensitive data.

## Product goal

The long-term direction is a developer desktop app that stays useful without network access, keeps secrets under zero-knowledge sync, and exposes a stable extension surface for plugins and AI agents.
