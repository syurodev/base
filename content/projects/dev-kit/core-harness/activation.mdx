# Activation và failure UX (G-07)

Trạng thái: foundation decision v0.10. **Thiết kế G-07 đã chốt**; gate chỉ đóng khi evidence ở [mục 5](#5-evidence-để-bật-giai-đoạn-a) đạt. G-07 vẫn đứng sau G-04 đến G-06: chưa có tool, provider và compatibility path được review thì không có gì để bật.

## 1. Hai giai đoạn

Quyết định của người dùng: native runtime bật **theo từng session** cho đến khi test xong, rồi **chuyển hẳn sang harness core của DevKit**.

| Giai đoạn | Hành vi | Điều kiện vào |
| --- | --- | --- |
| A — Opt-in theo session | Preference `harness.nativeRuntime` (mặc định tắt) chỉ hiện lựa chọn runtime khi tạo session. User chọn native hoặc vendor; vendor vẫn là mặc định | Evidence [mục 5](#5-evidence-để-bật-giai-đoạn-a) |
| B — Native mặc định | Session mới mặc định native; vendor còn chọn được để so sánh hoặc fallback | Tiêu chí [mục 6](#6-tiêu-chí-chuyển-hẳn-giai-đoạn-b) |
| C — Chỉ native cho session mới | Không tạo session vendor mới; session vendor cũ vẫn đọc được | Quyết định riêng sau B, kèm kế hoạch gỡ vendor runtime. **Không áp dụng cho subscription Claude**: native runtime không được dùng nó ([model adapter](/dev-kit/core-harness/model-adapter) M-03), nên Claude Code vẫn là đường dùng subscription. Với Codex, gói ChatGPT dùng được trong native runtime ([model adapter §11](/dev-kit/core-harness/model-adapter#11-openai-và-sign-in-with-chatgpt)), nên giai đoạn C có thể áp dụng |

Runtime **ghim theo session** từ lúc tạo, không đổi giữa chừng (G-06). Không chuyển session vendor thành native, không phản chiếu vendor history thành native events.

## 2. Phạm vi một session native ở giai đoạn A

- Bộ tool cơ bản của native ([tool system](/dev-kit/core-harness/tool-system)): file, tìm kiếm, shell, `job.*`, codegraph đọc, `harness.profile.propose`; tự chạy trong phạm vi grant theo preset của workspace.
- Tool nghiệp vụ (db, git, ssh…) chỉ được advertise khi version của nó `nativeCompatible`. Ratchet `prompt_sites_test.go` cho thấy mọi prompt site hiện còn `native-blocked`, nên các group này chưa có trong session native cho đến khi từng owner tách xong luồng confirm/select.
- Chỉ provider và account đã qua G-04; provider-hosted tools bị tắt.
- Không parallel tools, không team automation, không remote worker (ngoài v1).
- Execution history chỉ local (S-04). Vault phải mở để chạy hoặc resume (S-01, S-02).

## 3. Failure UX bắt buộc

Mỗi trạng thái dưới đây MUST có một màn hình hoặc banner trong Agent Hub, dùng read model, nói rõ chuyện gì đã xảy ra và hành động nào có thể làm. Không dùng thông báo lỗi chung chung.

| Tình huống | Hiển thị | Hành động |
| --- | --- | --- |
| Vault khóa sau process start | `Waiting(vault_locked)` kèm số run đang chờ | Mở vault; sau đó vẫn cần resume |
| Chờ resume sau restart | `Waiting(recovery_admission)` | `ResumeRun`, hoặc đóng run |
| Tác động không rõ | `Interrupted(effect_unknown)`: tool, attempt, thời điểm dispatch | Đối soát nếu owner hỗ trợ; `AcceptUnknown(close)` với preview đúng tham số khi vault mở; `CloseRunWithoutPayload` khi không xem được |
| Mất hoặc hỏng payload | `Interrupted(payload_unavailable)` | `CloseRunWithoutPayload`; run sau bắt buộc fresh context |
| Chọn context cho run mới | Lựa chọn fresh hoặc continue, khóa continue khi `fresh_required` | `SelectRunContext` |
| Worker treo, không có stop proof | "Cần khởi động lại DevKit để đóng run này"; nói rõ restart không chứng minh tác động bên ngoài đã dừng | Restart |
| Hết budget | Outcome `budget_exceeded` kèm loại budget (token, thời gian, tool calls, storage) | Tạo run mới với budget mới |
| Chờ worker | `Waiting(worker_capacity)` | Không cần làm gì |
| Data directory đang bị process khác giữ | Execution store unavailable, kèm đường dẫn data directory | Đóng process kia |
| Schema/protocol không hỗ trợ | Stream chỉ đọc, giải thích phiên bản | Nâng cấp DevKit |

Mọi preview chỉ hiện metadata cho phép theo INV-09; nội dung payload chỉ hiện khi vault mở, trong UI trusted.

## 4. Rollback

- Tắt `harness.nativeRuntime` ẩn lựa chọn native cho session mới. Session native đã có **không** bị xóa và không chuyển sang vendor.
- Khi tắt, session native cũ ở chế độ chỉ đọc: xem history, `CloseRunWithoutPayload`, `AcceptUnknown(close)`, xóa session. Không admit run mới.
- Execution store và bảng `exec_*` giữ nguyên; bật lại thì session tiếp tục theo guards hiện hành.
- Downgrade sang build không hiểu protocol: stream unavailable/read-only như [event storage §9](/dev-kit/core-harness/event-storage-recovery#9-payload-security-compatibility-và-client-delivery); không append, không đoán.

## 5. Evidence để bật giai đoạn A

Mọi mục kèm revision cụ thể; spike dữ liệu giả không tính.

- G-01 đến G-06 đã đóng; [evidence G-03](/dev-kit/core-harness/storage-security#10-evidence-để-đóng-g-03) đạt.
- Toàn bộ nhóm trong [tiêu chí kiểm chứng](/dev-kit/core-harness/decisions-and-validation#tiêu-chí-kiểm-chứng) đạt bằng test headless, với deterministic clock và fault injection.
- Mutation probes ở cùng trang đều làm test fail: bỏ CAS, bỏ current-authority check, dispatch khi replay, retry unknown, coi cancellation là stop proof.
- Một invariant checker SM-01–SM-12 chạy sau mỗi batch trong build test và dogfood; không có vi phạm.
- Mỗi hàng failure UX ở [mục 3](#3-failure-ux-bắt-buộc) có test UI hoặc e2e ở server mode, kể cả host headless (nil responder fail closed).
- Rollback ở [mục 4](#4-rollback) được chạy thử: bật, tạo session native, tắt, mở lại, bật lại.

## 6. Tiêu chí chuyển hẳn (giai đoạn B)

Chuyển từ A sang B khi **tất cả** đạt; con số dưới đây chỉ đổi bằng quyết định ghi lại.

| Tiêu chí | Ngưỡng |
| --- | --- |
| Dogfood | ≥ 14 ngày và ≥ 200 run native thật |
| Recovery drill | ≥ 20 lần crash hoặc kill có chủ đích ở các điểm: model stream, tool dispatch, chờ approval, commit unknown |
| An toàn | 0 vi phạm SM-01–SM-12; 0 effect bị dispatch hai lần; 0 lần `Interrupted` mà không giải thích được nguyên nhân |
| Tool coverage | Mọi tool user dùng thường xuyên trong session vendor đã có version native-compatible |
| Provider coverage | Mọi loại account đang dùng **mà điều khoản cho phép dùng trong ứng dụng bên thứ ba** đã có adapter qua G-04; subscription Claude không tính (M-03). Session mới chỉ mặc định native khi user có credential hợp lệ cho model đó, không thì mặc định vendor |
| Độ trễ | Từ lúc gửi prompt đến lúc model request rời DevKit, p50 không chậm hơn vendor nhanh nhất đã đo (Codex ≈ 2 s; Claude 4–7 s) |
| Compatibility | Session vendor cũ đọc được sau nâng cấp; rollback ở mục 4 vẫn chạy |

Giai đoạn C (không tạo session vendor mới, gỡ vendor runtime) là quyết định riêng sau B, không suy ra từ việc B đạt.
